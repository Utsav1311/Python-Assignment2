# Python Assignments — Practical 2

This folder contains the Python programs shown in the Practical-2 reference screenshots.

## Experiments

| File | Topic |
|---|---|
| `Experiment-A.py` | Python data types |
| `Experiment-B.py` | Type conversion |
| `Experiment-C.py` | Arithmetic, comparison, and logical operators |
| `Experiment-D.py` | Equality (`==`) vs identity (`is`) |
| `Experiment-E & F.py` | Mutability: lists, strings, and tuples |
| `Experiment-G.py` | List aliasing and copying |
| `Inventory-Challenge.py` | Dictionary aliasing and copying |

## Requirements

- Python 3.8 or newer
- No external packages are required

## Run a program

Open a terminal in this folder and run, for example:

```bash
python3 "Experiment-A.py"
```

Run any other experiment by replacing the filename. The programs are independent and can be executed separately.

## Notes

- `==` compares values, while `is` checks whether two names refer to the same object.
- Lists and dictionaries are mutable; strings and tuples are immutable.
- Assigning one variable to another creates an alias. Calling `.copy()` creates a separate shallow copy.
